# Mission Pilot 🚀

Mission Pilot is an **AI-powered learning chatbot** built to simplify knowledge sharing, fact extraction, and deliver quick, accurate responses in mission-critical scenarios.  

## 🌍 Designed for Critical Missions

This chatbot is tailored for situations where storing vital information and delivering instant responses are essential. Whether for organizations like **ISRO** during space missions or **DRDO** in defense research and disaster management, Mission Pilot ensures critical data is always accessible and easy to update.

---

## 💡 Core Features

### 1️⃣ Generate Facts Component
- Extracts essential facts from input text.
- How it works:
  - Counts word frequency and normalizes words.
  - Calculates sentence scores for relevance.
  - Extracts named entities (like `ORG`, `PERSON`, `GPE`, `PRODUCT`) for dynamic titles.
  - Uses subjects and noun chunks to identify key data points.
  - Stores all generated facts in a JSON file for easy retrieval.

### 2️⃣ View Facts Component
- View, edit, and delete stored facts effortlessly.

### 3️⃣ Mission Pilot Chatbot
- **Smart Response System**:
  - Answers queries based on stored JSON data.
  - Prompts user to provide answers to unknown queries and saves them for future use.
- **Voice Input & Output**: Makes interactions seamless and accessible in high-pressure scenarios.

---

## 🚀 Mission-Ready Advantages

- 🔑 **Critical Knowledge Storage**: Capture and manage essential facts in real time.
- ⚡ **Quick Responses**: Instantly provides answers, even during time-sensitive operations.
- 💡 **Dynamic Learning**: Learns and improves by asking for user input when facing unknown queries.
